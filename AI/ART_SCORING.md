# 模型艺术打分与模型质量打分

- Q-ReAlign Mini 0.8B，revision `fe1f45a7574c9e9d908875af9f7e90cb946aa19f`。
- 分别使用官方 IAA / IQA 提示词，Apple Metal GPU / bfloat16 / SDPA / batch 1；不启用 CPU fallback。
- ImageIO / Core Image 从首选照片生成长边 768px 的旋转后 SDR/sRGB JPEG；RAW 配对只处理首选照片，跳过视频。独立的缓存指纹避免复用 512px Embedding 输入。
- 本地已有环境通过不入库的 `.local/ai-config.json` 设置 `artPython` 和 `artModel`，保留模型目录旁的 `model-revision.json`。分发构建不包含本地路径。
- 原始 0–1 分数、输入指纹、模型/管线标识、更新时间保存在本机图录目录 `ArtScores/scores.sqlite（艺术）与 QualityScores/scores.sqlite（质量）`；WAL + FULL，每张提交，缓存清理不删除评分。失败 ID 保存在同目录 `failed.json`。
- 两项共用固定 PCHIP 映射 v2：原始百分制 [0,20,40,50,60,70,80,90,100] → [0,0.4,1.5,2.2,3.1,4.2,4.9,4.97,5]，展示两位小数。按未四舍五入的原始分数排序，与单调映射等价；未评分/失效/视频最后。
- 每个目录的分析范围由目录与含子目录开关决定，不使用搜索、星级、标签过滤。手动补全跳过有效结果；暂停在当前推理提交后生效；失败可单独重试。
- 艺术分与手动星级无关联，不写原文件。源文件变化、旋转、模型管线变化后旧分数不参与显示和排序。父目录合并沿用资产身份路径，保留结果。
- 评分时后台最多两个解码预取，模型串行推理；任务结束保留共享模型，空闲 180 秒后释放；美学与画质任务共享 Q-ReAlign 权重，数据库仍隔离。大图库指纹复用，刷取期间艺术排序最多约每三秒刷新一次，结束后立即刷新。
- 左侧已保存的筛选器、标签、AI 分析折叠状态用 AppStorage 保留。启动读取评分状态，不自动推理。

## 验证
- `zsh scripts/test-art-scoring.sh`：全区间单调/端点、控制点、升降序、空值末尾、旋转失效、父目录合并身份、递归范围。
- 构建后 `zsh scripts/test-art-integration.sh`：隔离临时图库中完整解码/推理/落盘、暂停续跑、范围隔离、失败落盘/重试。需要现有离线模型，并通过 `PHOTOLAB_TEST_IMAGE` 指定测试 JPEG。
- `zsh scripts/test-scale-integration.sh`：原有扫描、标记并发、撤销、最新查询、离线保留、目录移除/合并回归。
- 已验证正式 Python worker 的两个样本输出与离线 IAA 结果一致；进程重启后跳过已完成结果。
- 实际 App 验证 test_photo：两组 RAW 配对分别评分，视频跳过，网格/详情展示、艺术分排序正常。

质量分独立指纹与数据库，768px 解码缓存与艺术分共享；评分值不混合。网格简写艺术/质量，详情与分析模块保留完整名称。映射调整只影响显示，不改动历史原始分数。
